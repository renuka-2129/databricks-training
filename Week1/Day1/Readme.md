# Week 1

This folder contains SQL practice tasks and learning materials completed as part of the Databricks training program. The work focuses on understanding SQL fundamentals, writing queries, and practicing database operations using sample datasets.

## Day 1
- SQL basics
- DB Fiddle practice
- Schema creation
- Query practice
- Data filtering using `WHERE`
- Pattern matching using `LIKE`
- Aggregate functions (`SUM`, `AVG`, `MIN`, `COUNT`)
- `GROUP BY` operations
- Date-based queries using `YEAR()` and `MONTH()`

### Files Included
- `schema.sql` – Table creation and sample data insertion
- `queries.sql` – SQL queries practiced during the session
- `output.txt` – Query outputs and results

### Learning Outcomes
- Improved understanding of SQL query writing
- Learned how to filter and analyze data
- Practiced grouping and aggregation concepts
- Gained hands-on experience using DB Fiddle and GitHub
